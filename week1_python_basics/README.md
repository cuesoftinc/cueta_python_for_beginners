# Week 1 — Python Basics (From Zero to Problem Solving)

You’ll practice thinking like a programmer while writing clean, testable Python.

## You will learn
- Variables, types, expressions
- Strings, lists, dicts
- Control flow, loops
- Functions & type hints
- File I/O and basic error handling
- Test-driven iteration (red → green)

## Do this
1) Open `student/homework.py` and implement each function.
2) Run tests:

    python run_tests.py

Fix failures until all pass.
3) (Optional) Compare to `solutions/homework.py` and read `solutions/explanation.md`.

## Structure
- `student/`: the file you edit (`homework.py`).
- `solutions/`: reference answers and `explanation.md`.
- `tests/`: the tests `run_tests.py` runs.
- `data/`: sample input for the tasks.
- `run_solution_tests.py`: runs the same tests against `solutions/` (for instructors).
