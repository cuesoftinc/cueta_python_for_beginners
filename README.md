# Python for Beginners

A four-week, offline course that takes a learner from Python basics to a first machine-learning model. Every week is a folder of tests-first exercises written with the Python standard library only.

| Week | Folder                | Topic                                 |
| ---- | --------------------- | ------------------------------------- |
| 1    | `week1_python_basics` | Python basics and problem solving     |
| 2    | `week2_data_handling` | CSV handling, aggregation and ranking |
| 3    | `week3_ml_intro_knn`  | A k-nearest neighbors classifier      |
| 4    | `week4_text_intro_nb` | Naive Bayes sentiment on text         |

## Prerequisites

Python 3 with `unittest`, which ships with it. There is nothing to install.

## How to use

1. Open a week's folder.
2. Implement the functions in its `student/` file.
3. Run `python run_tests.py` from that folder until every test passes.
4. Compare with the `solutions/` folder only after you try your best.

Instructors can check a week's reference answers with `python run_solution_tests.py`, run from the same folder.
